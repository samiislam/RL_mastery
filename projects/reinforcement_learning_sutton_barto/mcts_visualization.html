1. Selection

  • Start at root node
  • Use UCB tree policy
  • Balance explore vs exploit
  • Stop at expandable node

2. Expansion

  • Single: Add one child node
  • All: Add all children at once
  • Tree grows incrementally
  • Skip if node is terminal

3. Simulation

  • Run rollout to terminal
  • Use random policy
  • Collect return (R)
  • Nodes not saved to tree

4. Backup

  • Propagate R upward
  • Update visit count (n)
  • Update value (V)
  • Continue to root
